⚙️ Configuração do GitHub

Configure o token do GitHub para publicar posts e alterações diretamente no site sem precisar abrir o GitHub.

Crie em: github.com/settings/tokens — selecione o escopo repo. O token é salvo apenas no seu navegador (localStorage).
